# نموذج باقات لا بيزل

النموذج الحالي يواصل ملفات وهوية لا بيزل. الصفحة الرئيسية هي `index.html`، والتفاعل في `assets/bouquet.js` والتنسيقات في `assets/bouquet.css`.

## فتح التجربة

يمكن فتح `index.html` مباشرة لتخصيص الباقة والحفظ المحلي. نسخة GitHub Pages ثابتة، لذلك لا تشغّل `server.mjs` ولا تتيح توليد الصور الواقعية؛ يوضّح الموقع هذا القيد ويُبقي التصميم والحفظ والمشاركة متاحة. لتشغيل مسارات الخادم محليًا استخدم **Node.js 22 أو أحدث**، ومن مجلد المشروع شغّل:

```powershell
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
node server.mjs
```

ثم افتح `http://127.0.0.1:4177`. لا توجد حزم خارجية مطلوبة، ولا تحتاج إلى `npm install`.

## إعداد توليد الصور

### خيار مفتوح المصدر للزبائن

التكامل الاختياري المقترح لخادم صور مستقل يعمل بنموذج FLUX.2 Klein 4B مفتوح الأوزان غير متاح في نسخة GitHub Pages الثابتة. ملفات خدمة GPU المشار إليها في مذكرة التسليم غير موجودة في هذا المصدر؛ لا يتصل متصفح العرض بخدمة صور ولا يرسل إليها بيانات.

خدمة GPU وخادم التطبيق تحتاجان إعدادًا واستضافة منفصلين قبل إتاحة هذه الوظيفة. لم يُشترَ خادم ولم تُنشر الميزة للزبائن.

### خيار OpenAI الحالي

ضع المفتاح في `.env` فقط:

```dotenv
OPENAI_API_KEY=
OPENAI_IMAGE_MODEL=gpt-image-2.5-sunburst
IMAGE_GENERATION_ENABLED=true
PREVIEWS_PER_HOUR=4
```

املأ قيمة المفتاح بعد علامة `=`، ثم احفظ الملف وحدّث صفحة المتصفح. يقرأ الخادم المفتاح وإعداد النموذج ورقم واتساب من `.env` عند طلب الخدمة، دون إعادة تشغيل. يجب أن يملك حساب الخدمة صلاحية استخدام النموذج وفوترة متاحة. يمكن تغيير النموذج إلى نموذج صور متاح لحسابك يدعم مسار التحرير نفسه.

ملف `.env` المحلي مجهّز بمفتاح فارغ. افتحه في محرر النصوص على جهازك، وأضف المفتاح بعد `OPENAI_API_KEY=`؛ لا ترسله في المحادثة. لا تستبدل ملف الإعدادات إذا كنت قد أضفت إليه مفتاحًا أو رقم المتجر.

بعد الحفظ افتح `http://127.0.0.1:4177/api/config`: تصبح `imageEnabled` مساوية لـ `true` عندما يكون المفتاح موجودًا والتوليد مفعّلًا. هذا فحص إعداد محلي، ولا يثبت صلاحية المفتاح أو الفوترة لدى المزوّد؛ أول طلب توليد ناجح يثبت عمل الخدمة. لتجربة الصورة افتح الصفحة عبر عنوان الخادم، وليس كملف مستقل داخل عرض ثابت. تحتاج إعادة التشغيل فقط عند تغيير المنفذ أو المضيف أو حد عدد الصور في الساعة.

الزر يستخدم صورة التصميم النظيف واختيارات الزهور وألوانها ومواقعها والتغليف والربطة. لا يرسل رسالة الإهداء. يرسل الخادم طلبًا حقيقيًا إلى خدمة الصور فقط عند ضغط العميل زر التوليد؛ قد يترتب على ذلك استهلاك مدفوع في حساب الخدمة. توجد حالة انتظار وإلغاء ورسائل أخطاء، ويُلغى اعتماد الصورة القديمة عند تعديل التصميم. الصور تبقى في ذاكرة الصفحة ولا تُحفظ على الخادم.

الربط يستخدم [مسار تحرير الصور الرسمي لدى OpenAI](https://developers.openai.com/api/reference/resources/images/methods/edit)، بصورة مرجعية وبيانات اختيار منظّمة. لا توجد صورة تجريبية ثابتة تُعرض على أنها نتيجة اختيار العميل.

**الحالة عند التسليم:** لم يُضف مفتاح خدمة ولم تُنفّذ عملية توليد حقيقية عبر الخادم. يظل الزر غير متاح حتى تهيئة الخدمة. لا تضع المفتاح في `index.html` أو `assets/`؛ هذه الملفات تُرسل للمتصفح. الخادم لا يتيح تنزيل `.env` أو مصدره عبر مسارات الملفات العامة.

## إعداد واتساب

رقم واتساب المتجر مضبوط حاليًا في `.env` و`assets/bouquet-config.js` بصيغته الدولية. عند تغييره، ضعه في `.env` بالأرقام فقط، دون `+` أو مسافات، ثم حدّث الصفحة:

```dotenv
WHATSAPP_NUMBER=
```

عند استخدام الصفحة كملف مستقل يمكن وضع الرقم العام في `assets/bouquet-config.js` بدلًا من `.env`. إعداد الخادم له الأولوية عندما يكون رقمًا صالحًا.

في خطوة المراجعة، زر «شارك صورة الباقة وتفاصيلها» ينشئ صورة PNG واحدة تجمع التنسيق وقائمة التفاصيل والسعر التجريبي، ثم يفتح قائمة المشاركة في الأجهزة والمتصفحات التي تدعم مشاركة الملفات. يختار العميل واتساب ومحادثة المتجر ويؤكد الإرسال بنفسه. قد يختلف دعم النص المرافق بين التطبيقات؛ التفاصيل مكتوبة أيضًا داخل الصورة نفسها. زر «احفظ صورة الباقة وتفاصيلها» ينزّل الصورة ذاتها للعميل.

رابط «افتح واتساب المتجر» يفتح محادثة المتجر برسالة نصية جاهزة. لا يستطيع رابط واتساب إرفاق ملف الصورة تلقائيًا؛ في المتصفحات التي لا تدعم مشاركة الملفات، يحفظ العميل الصورة ثم يرفقها في المحادثة. لا يُعد فتح واتساب طلبًا مؤكدًا. يراجع المتجر التوفّر وإمكانية التنفيذ والسعر النهائي، ثم يرسل طريقة الدفع، ويبدأ التنفيذ بعد الدفع.

عندما يكون الرقم فارغًا لا يوجد رابط إرسال إلى رقم بديل؛ تبقى المشاركة عبر قائمة النظام والنسخ والحفظ متاحة، ويختار العميل محادثة المتجر بنفسه.

## حدود النسخة

- جميع الأسعار توضيحية، والتوفّر والسعر والتنفيذ يحتاجون مراجعة المتجر. لا يوجد دفع أو ربط بسلة زد.
- أحجام الزهور نسبية وليست قياسات نباتية أو مقاسات منتج مضمونة؛ تختلف بالصنف ودرجة التفتح.
- صور التغليف والزهور والربطات أصول مولّدة للمعاينة. لها نسخ محلية، ولا تُحمّل من مواقع خارجية أثناء التخصيص.
- الصورة الواقعية توقع مولّد؛ قد تختلف التفاصيل والعدد الدقيق عن التنفيذ الطبيعي. لا تحل محل مراجعة المنسّق.
- التخزين المحلي يحفظ التصميم والألوان والمواقع والحجم والربطة، ويفتح التصاميم المحفوظة بالإصدارات السابقة.
- في خطوة «اللمسات»، فعّل الربطة ثم اسحبها داخل المعاينة، أو استخدم أزرار الاتجاه. مؤشر الزاوية يدور من ‎-٦٠ إلى ‎٦٠ درجة، وزر إعادة الضبط يعيد وضعها الأصلي. يحفظ التصميم موضع الربطة وزاويتها ويمررهما إلى طلب الصورة ورسالة واتساب، دون تغيير السعر بمجرد التحريك أو التدوير.
- الخادم مُعدّ محليًا على `127.0.0.1`، ولم يُنشر. الحد الافتراضي أربع معاينات لكل عنوان عميل في الساعة وطلبان متزامنان. النشر التجاري يحتاج إعداد الاستضافة وصلاحيات الاستخدام الملائمة؛ هذه النسخة لا تضيف حسابات أو نظام طلبات مؤكدًا.

## فحوص المصدر

ملفات الاختبار المشار إليها أدناه غير موجودة في هذه الحزمة؛ لذلك لا يُدّعى نجاح اختبارات `tests/`. يفحص GitHub Actions مراجع الملفات المحلية في HTML وCSS ثم ينشر الملفات الثابتة فقط.

```powershell
node --test tests/server.test.mjs tests/bouquet.test.mjs
```

تستخدم فحوص الخادم استجابة خدمة محاكية ولا تستهلك رصيد OpenAI ولا ترسل رسائل واتساب.
